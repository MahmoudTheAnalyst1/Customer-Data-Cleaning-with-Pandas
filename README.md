# Customer Data Cleaning with Pandas

## Project Overview
This project focuses on cleaning and preparing customer data using Python and Pandas.

## Data Cleaning Tasks
- Handling missing values
- Replacing invalid values
- Cleaning customer information
- Splitting the Address column into:
  - Street Address
  - State
  - Zip Code
- Preparing the data for further analysis

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Project File
- `Customer_Data_Cleaning_Project.ipynb`
